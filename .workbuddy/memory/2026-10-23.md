# 2026-10-23

## GithubSrcReader 基础框架搭建（Android / Compose + Miuix）

**目标**：查看 GitHub 云端代码 + 本地文件夹代码的阅读器，界面走 Miuix（澎湃/HyperOS）风格，底栏悬浮。

**技术栈**
- AGP 9.4.0（内置 Kotlin，不能应用 `org.jetbrains.kotlin.android`，否则构建报错）
- Kotlin 2.4.21 + Compose BOM 2026.09.00（compose 1.12.1）
- Miuix 0.9.4：`miuix-ui-android` / `miuix-icons-android` / `miuix-squircle-android`（blur 需 minSdk 33、preference/nav 暂未启用，已注释）
- OkHttp 4.12.0 + `org.json`（不引序列化插件）、Navigation Compose 2.9.7、documentfile 1.1.0

**关键坑（重要）**
1. Miuix 0.9.4 用 Kotlin 2.4 编译（metadata 2.4.0），AGP 9 内置 Kotlin 2.2.10 只能读到 2.3.0 → 必须升级编译器。
2. AGP 9 下不能 apply KGP 插件；正确做法是在根 `build.gradle.kts` 的 `buildscript.dependencies` 加
   `classpath("org.jetbrains.kotlin:kotlin-gradle-plugin:2.4.21")`，内置 Kotlin 的版本由此决定。
3. Miuix 0.9.4 依赖 compose 1.12.x，BOM 必须 ≥ 2026.09.00，否则运行期不匹配。
4. Miuix 的 `FloatingNavigationBar` 会把传入的 modifier 应用在内部 Row 上，不能直接用它做 Box 对齐；
   需要在外面套一层 `Box(Modifier.align(BottomCenter))`。

**结构**
```
data/  model/(Models, Language, CodeSource) github/(GitHubUrlParser, GitHubApi, GitHubCodeSource)
       local/LocalCodeSource(SAF) TextReader AppPreferences
ui/    code/(CodeTokenizer, CodeBlock, CodeColors) theme/Theme.kt
       components/(AppBottomBar, FileRow) screens/(Home, Browse, Viewer, Settings)
       AppViewModel AppUiState AppRoot MainActivity
```
- 源码统一抽象 `CodeSource`（list/readText），GitHub 与本地文件夹共用浏览/阅读界面。
- 顶部栏用 `SmallTopAppBar`，底栏用 `FloatingNavigationBar`（悬浮），Viewer 路由隐藏底栏。
- 语法高亮为手写词法扫描（CodeTokenizer），只输出 token 区间，着色在 Compose 层做，支持 Kotlin/Java/Python/JS/TS/Go/Rust/C/C++/C#/Swift/SQL/JSON/YAML/XML/HTML/CSS/Markdown 等。

**验证**：`./gradlew :app:assembleDebug` 通过；`testDebugUnitTest` 12 个用例全绿（URL 解析 7、词法 4、示例 1）。

## 迭代：代码预览双指缩放 + release 签名打包

- `CodeBlock` 新增双指缩放：`zoom` 用 `rememberSaveable` 保存，范围 0.7x~3.0x；
  实现方式是**按 zoom 重算 fontSize/lineHeight**（13sp/19sp × zoom），而不是 graphicsLayer 缩放——
  文字始终按原生分辨率渲染不糊，且滚动范围会跟着内容自动更新。
- 手势：外层 Box 用 `awaitEachGesture` + `awaitPointerEvent(PointerEventPass.Initial)`，
  **只在 changes.size > 1 时** `calculateZoom()` 并 consume 多指事件；单指拖动仍交给内层
  `verticalScroll/horizontalScroll`，Initial 阶段先于子节点消费可避免缩放时滚动抖动。
- `LaunchedEffect` 的跳转定位改用 sp 换算（`(19f*zoom).sp.toPx()`，兼容系统字体缩放），并把 zoom 加入 key。
- release 打包：新增 `keystore/githubsrcreader.jks`（CN=GithubSrcReader，10 年有效期），
  签名信息读根目录 `keystore.properties`（已加入 .gitignore）；`app/build.gradle.kts` 里
  `signingConfigs.create("release")`，文件缺失时降级为不签名，不会卡住别人的构建。
- AGP 9 的 `buildTypes.release` 用 `optimization { enable = false }`（旧的 `isMinifyEnabled` 已不适用）；
  本次**未开 R8**，release 30MB（dex 29MB），需要更小包时可把 `optimization.enable` 改 true。

## 迭代：令牌密文化 + 澎湃风格左对齐标题

- 新增 `data/security/SecretVault.kt`：Android Keystore 里的 AES-256-GCM（别名 `ghsr_secret_v1`，256 位，
  密钥不落盘），密文格式 `v1:base64(iv):base64(payload)`，带 GCM 认证标签；加解密失败返回 null，
  **绝不回退明文**。Base64 用 `java.util.Base64`（minSdk 31 安全）。
- `AppPreferences`：token 改为读 `token_cipher`（密文）+ 内存缓存；旧键 `token` 明文在首次读取时
  自动迁移成密文并删除；新增 `hasToken`。加密失败时宁可不存也不写明文。
- `SettingsUiState` 去掉 `token`，改为 `tokenDraft` + `hasToken` + `message`：保存后立即清空草稿，
  界面只显示「已保存 · 密文存储 / 未设置」，永不回显。
- 设置页输入框用 Miuix `TextField(TextFieldValue)` 重载 + `PasswordVisualTransformation` +
  `KeyboardType.Password`（String 重载没有 visualTransformation，这点要注意）。
- 新增 `ui/components/AppTitleHeader.kt`：30sp 加粗、-0.5sp 字距、左对齐、可带副标题与右侧操作，

## 迭代：接收系统分享

- Manifest 给 MainActivity 加了 `ACTION_SEND` + `text/plain` 过滤器（launchMode 仍是 singleTask，
  已运行的实例走 `onNewIntent`）。Android 无法按内容过滤，所以任何文本分享都会出现本应用，
  解析失败时给提示而不是静默。
- `data/github/SharedLink.kt`（纯 Kotlin）：从任意分享文本里挑第一个可解析链接——
  先整段尝试（支持 `owner/repo` 简写），再正则找带协议 URL，最后找无协议的 `github.com/...` 片段；
  `clean()` 会截掉说明文字、去首尾括号/引号/中文标点。
  **坑**：`GitHubUrlParser.parse` 会忽略 `://` 之前的内容但不会报错，所以必须自己截出 URL 起点，
  否则返回值里会带着「看看这个 」这种前缀。
- `AppViewModel.openSharedText()`：解析成功走 `openUrl`；失败则回首页并提示，
  为此新增 `AppEvent.ShowHome`（AppRoot 里 reset 到 HOME）。
- `SharedLinkTest` 9 个用例（含 Markdown、中文标点、query/hash、git@ 形式），累计 31 个用例全绿。
